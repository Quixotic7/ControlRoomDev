This should sort oldest comments first with an icon you can click to change sort order. 

## Backlog refinement

Prepared by Codex backlog refinement. This describes planned work; implementation has not started.

### Intended outcome

Read a ticket’s conversation in chronological order by default, with a simple icon control to switch to newest-first when desired.

### Scope and approach

Default ticket conversations to oldest-first. Add a visible sort-direction icon next to Conversation with a tooltip, accessible name, and current order. Remember the selected preference per project. This controls comments inside a ticket, independently of the newest-first project activity feed in #25.

### Acceptance criteria

- [ ] Opening a conversation without an existing preference shows comments from oldest to newest, ordered by their recorded timestamps rather than filenames or record enumeration order.
- [ ] Clicking the sort control switches between Oldest first and Newest first; all comment types participate in the same consistent order.
- [ ] Equal timestamps use a deterministic secondary key, and changing order neither duplicates nor loses entries.
- [ ] The chosen order persists across closing/reopening and refresh through the project preference model.
- [ ] New comments appear in the correct position without forcing a reader away from older content; after posting, the author can readily find their own new comment.
- [ ] Keyboard users can toggle the icon, and its label/tooltip communicates the current order and available action. Existing comment resolution and review summaries continue to work.

### Implementation notes and related work

Inspect src/store.ts comments enumeration and web/RecordDetail.tsx conversation mapping, plus the existing preference plumbing in web/App.tsx and src/server.ts. Apply presentation sorting without changing stored timestamps or the chronological history available to agents.

### Human review / verification

Use a conversation with mixed comment types, deliberately nonchronological record filenames, and equal timestamps. Check the default, toggle both directions, post a comment, reload, and confirm no entry disappears or changes content.
