If the LLM has questions about a ticket, they can add a questionaire with multiple choice questions or text questions to a ticket and mark it as needing human feedback. 

## Backlog refinement

Prepared by Codex backlog refinement. This describes planned work; implementation has not started.

### Intended outcome

Let an agent attach a structured questionnaire to a ticket and request human input, keeping questions and answers in the ticket’s conversation.

### Scope and approach

Support one or more multiple-choice or free-text questions, an explicit needs-feedback state, and answering at the human’s pace. Store structured data durably in Markdown records/metadata and expose it through CLI/MCP context. Keep this distinct from mandatory ticket creation forms.

### Acceptance criteria

- [ ] An agent can submit a questionnaire with stable question IDs, clear prompts, answer types, and optional recommended choices; users can provide custom text where choices are offered.
- [ ] The ticket appears in Needs you with a direct route to its unanswered questionnaire; a separate flag does not silently change its workflow stage.
- [ ] Questions never time out or disappear because the user pauses. Draft answers persist across closing/reopening and refresh, and can be submitted explicitly.
- [ ] No recommended/preselected option counts as an answer until the human submits; required unanswered questions remain visible.
- [ ] Submitted answers retain human attribution, question wording, and timestamps in the conversation, and are readable by agent context and wait-for-update workflows.
- [ ] Question edits/replacements and amended answers retain history; stale submissions do not overwrite a newer questionnaire, and resolving one request does not clear unrelated open questions.

### Implementation notes and related work

Extend src/types.ts, src/store.ts comments/context, src/server.ts, src/cli.ts/src/mcp.ts, web/RecordDetail.tsx and web/model.ts attention handling. Reuse the existing question/resolve flow where possible. Related: #26.

### Human review / verification

Submit a mixed questionnaire, leave it unanswered beyond ordinary UI timers, save a partial draft, reload, and finish later. Confirm that an agent receives the explicit answers and that a concurrent question edit triggers reconciliation.
