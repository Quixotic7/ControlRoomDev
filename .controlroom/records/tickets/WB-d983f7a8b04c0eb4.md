## Backlog refinement

Prepared by Codex backlog refinement. This describes planned work; implementation has not started. Proposed behavior below remains subject to human scope review.

### Intended outcome

Navigate directly from a child ticket to its parent without searching the board or using the parent-selection editor.

### Scope and approach

Show a clearly labeled parent link with the parent's ticket number and short title near the top of ticket details. Keep this navigation separate from changing the parent relationship. Follow existing ticket-link behavior, including middle-click and modifier-click opening a separate tab.

### Acceptance criteria

- [ ] A child ticket shows a keyboard-accessible Parent: #number title link; clicking it opens the correct parent's detail dialog.
- [ ] Same-tab navigation saves pending edits first using the existing autosave/conflict behavior. A failed save keeps the child draft open and explains the failure.
- [ ] Middle-click/modifier-click opens the parent in a separate tab while leaving the current ticket and its draft intact; the resulting URL survives refresh.
- [ ] An archived parent remains navigable and is clearly marked Archived; navigation does not unarchive or reparent anything.
- [ ] A ticket without a parent has no misleading navigation target. A missing parent shows an unavailable state without crashing or silently discarding the stored relationship.
- [ ] Changing the parent updates the navigation target consistently after saving. The parent picker continues to edit the relationship independently.
- [ ] Long titles remain usable at compact/mobile widths, with accessible link names that include the ticket number and title.

### Implementation notes and related work

Reuse web/ticketNavigation.ts from #42 and RecordDetail's save-before-child-navigation pattern. Inspect web/RecordDetail.tsx and web/ParentInput.tsx. Related: #14 child management, #15 parent selection, #42 new-tab navigation. Breadcrumb navigation across the full ancestry and a new navigation-history system are outside this scope.

### Human review / verification

Open a child, edit its description and navigate to its parent, then reopen the child to verify persistence. Try keyboard, middle-click, an archived parent, a long title and a failed/conflicting save.
