## Finding

When the local service is stopped, running the outer ControlRoomDev launcher with a command such as ./workboard list fails to start it. The child process imports tsx by package name from the inherited working directory, but node_modules now lives inside ControlRoom/.

## Reproduction and evidence

Reproduced from ControlRoomDev against an empty temporary board. The command exited 1 with "Service did not start"; its service log contained ERR_MODULE_NOT_FOUND: Cannot find package tsx imported from the outer kanbantool directory. The existing live service was not stopped.

## Acceptance criteria

- [ ] Resolve the TypeScript loader relative to the tool installation, independently of the caller working directory.
- [ ] With no service running, list/show and MCP can start and connect from the outer repository and another caller directory.
- [ ] Preserve startup for installed bundled JavaScript builds and source checkouts.
- [ ] Add an integration test that starts from a directory without node_modules and cleans up its temporary service.
