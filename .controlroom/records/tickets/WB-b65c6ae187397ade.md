Already experiencing effects, maybe have a way to quick archive the "Done" swimlane and also a way to go back and view past archived done tickets and unarchive return to active if possible

## Backlog refinement

Prepared by Codex backlog refinement. This describes planned work; implementation has not started. Proposed behavior below remains subject to human scope review.

### Intended outcome

Clear completed tickets from the active board quickly, while keeping their history easy to browse and restore.

### Scope and approach

Add an Archive completed tickets action to a Done-status column header. Proposed first-release behavior: archive only unarchived tickets in that column that match the current view/search filters, across its visible groups. Before applying, show the exact count and scope, with a way to inspect the affected tickets. Provide an obvious Archived tickets view with search and an Unarchive action.

Unarchiving returns a ticket to the active board in its existing workflow stage (usually Done); moving it back into development remains a separate explicit action. Archiving a parent does not implicitly archive its children. This is a focused implementation follow-up to #23; it need not wait for every clutter-management recommendation.

### Acceptance criteria

- [ ] A Done-role column offers the archive action, including renamed/custom Done columns; non-Done columns do not silently offer the same completed-work operation.
- [ ] The preview names the column, filter scope and affected ticket count. Empty sets are harmless; cancel changes nothing. Tickets outside the preview are never archived.
- [ ] Each write uses the previewed ticket revision. Concurrent changes are rejected for that ticket, with clear success/failure counts and a refresh/review path; no stale record is overwritten.
- [ ] Archived tickets disappear from ordinary active views and remain searchable in an explicitly labeled archive view.
- [ ] A ticket can be opened and unarchived from the archive view. Its status, number, prose, comments, attachments, decisions and parent/child links survive the round trip.
- [ ] Archiving preserves decision/rule discovery and does not delete local screenshots or implicitly archive linked records.
- [ ] The action and archive navigation work with keyboard input, and the chosen scope stays explicit when filters or column visibility change.

### Implementation notes and related work

Reuse the existing archived metadata and is:archived filtering in web/model.ts and the detail Unarchive action. Inspect web/BoardView.tsx, web/ProjectPage.tsx and revision-checked record updates in src/store.ts. Related: parent #23, #17 bulk actions, #46 column visibility. Scheduled/automatic archiving and deletion are outside this ticket.

Verify unrelated tickets and linked project knowledge remain intact. Exercise a concurrent edit during the preview to confirm it is reported rather than overwritten.
