## Finding

startMcp assigns cwd = store.root. The canonical board directory is used for verification commands, default claim paths, branch detection, and commit collection, even when the agent is working in a submodule or a separate worktree. In this project, the board repository is ControlRoomDev while application code is in ControlRoom/.

## Reproduction and evidence

Started the MCP process from a nested agent-checkout directory against a temporary shared board. submit_review with the harmless command pwd recorded the board root as both verification.cwd and output, rather than the launch directory.

## Acceptance criteria

- [ ] Keep canonical board storage separate from the agent execution directory.
- [ ] Use the agent checkout for verification, default claims, branch detection, and commits_since, with a documented way to specify it.
- [ ] Starting MCP in a submodule or linked worktree still reaches the shared board but verifies code in that checkout.
- [ ] Add integration coverage that distinguishes board and code directories and confirms the recorded branch/commits belong to the code checkout.
