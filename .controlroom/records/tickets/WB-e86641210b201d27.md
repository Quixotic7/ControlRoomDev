Requested by the JuiceLab coordinator (JuiceLab board #33, owner asked for Control Room tickets in chat, 2026-10-01).

## Problem

Claude workers are launched as `claude -p --permission-mode acceptEdits --max-turns N [--model M]`
(`src/agent-runner.ts`). In that mode a headless worker may edit files, but every Bash command that is not
allow-listed in the user's or the project's Claude settings is denied. On JuiceLab there are no allow rules, so a
managed Claude worker can edit but cannot build, run the self-test, run a test script or commit. The README says
permission denials "require human attention", but there is no place on the Agents page to grant what a project's
workers need. The only way today is a wrapper script as the profile's executable that injects `--settings`; an
agent writing such a launcher for other agents is (rightly) refused by Claude Code's safety classifier, so it has
to be a human-approved setting of the tool.

There is also no way to give a profile a role: every worker gets the same instruction text, whatever its model.

## Wanted (all configured by a human on the Agents page, stored in the board's `.controlroom/`)

- Project worker permissions: a list of allowed command patterns for Claude workers (passed as `--allowedTools`
  or a generated `--settings` file) and the equivalent for Codex, shown in full to the human who approves them.
- Extra readable/writable directories per project (Claude `--add-dir`), e.g. an evidence folder outside the repo.
- Environment variables for worker and verification processes (JuiceLab needs three module-cache variables).
- A project worker brief (Markdown in `.controlroom/`, e.g. `.controlroom/agents/worker-brief.md`) appended to
  every worker prompt, and an optional per-profile role note (e.g. "principal engineer: audio-thread work").
- The effective launch command (without secrets) visible in the run's detail, so a human can see what a worker
  was allowed to do.

## Acceptance criteria

- With `swift build`, the project's test commands and `git add`/`git commit` allowed, a managed Claude worker on
  JuiceLab builds Machine Lab, runs `--selftest Examples`, and commits, with no permission denials in its log.
- A command outside the list is still denied and reported as needing human attention.
- Only a human can change these settings; an agent caller gets 403.
