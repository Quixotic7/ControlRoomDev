## Backlog refinement

Prepared by Codex backlog refinement. This describes planned work; implementation has not started.

### Intended outcome

Give users a Help/Playbook tab with short, copyable prompts for working with their existing coding agent and this project board.

### Scope and approach

Provide concise recipes for connection/setup, refining Concept tickets, planning an approved parent, picking up work, reporting progress, submitting review evidence, responding to feedback, documenting decisions, and maintaining the rulebook. Include screenshot feedback and shortcut help; no embedded provider or agent execution is required.

### Acceptance criteria

- [ ] An in-app Help/Playbook entry offers searchable or clearly grouped recipes, each with its purpose, prerequisites, and a short copyable prompt.
- [ ] Prompts use real project context where available and clearly mark user-supplied placeholders; copied text contains no local auth tokens or hidden secrets.
- [ ] Ticket-specific recipes use public numbers with shell-safe examples and explain scope approval, claims, Review, and human acceptance.
- [ ] Setup guidance matches the shipped CLI/MCP protocol; the source stays easy to update alongside AGENT_GUIDE.md.
- [ ] Copy confirms success accessibly, supports keyboard use, and has a fallback if clipboard access is unavailable.
- [ ] The playbook works offline and lets the user choose where to paste/run a prompt; clicking Copy does not start an agent or mutate tickets.

### Implementation notes and related work

Start with AGENT_GUIDE.md, CLI help, web/Shortcuts.tsx, web/TopNav.tsx and web/Pages.tsx. Prefer a small shared content source to duplicated instructions that drift. Related: #27 for collecting human answers.

### Human review / verification

Follow the setup and review recipes against a disposable project using current CLI commands. Copy a ticket-specific prompt and verify correct number/context, no secrets, and no automatic execution.
