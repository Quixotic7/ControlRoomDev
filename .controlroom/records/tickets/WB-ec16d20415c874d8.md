## Intended outcome

Reduce the maintenance cost of a project-local tool. Provide a guided installer and diagnostics that explain runtime, canonical checkout, service availability and version mismatches. Keep records separate from application upgrades.

## Acceptance criteria

A fresh user can install and open a project with one documented command; existing worktrees discover the same board; upgrade failure leaves records intact and offers rollback; diagnostics provide actionable recovery without exposing secrets.
