## Choice

The service stamps progress reports with the acting identity and timestamp. Optional percentages are bounded from 0 to 100 and labeled estimates. Entering an In Progress role from another role starts a new session timestamp; moves between In Progress columns retain the session. Prior sessions remain in record history. Displayed elapsed time is derived in the browser rather than written periodically to disk.

## Context and rationale

The tool coordinates agents but does not supervise their execution. A claim or recent report is not proof that an agent process is running. Expired claims and reports older than 30 minutes are labeled explicitly. A percentage, elapsed timer or completed checklist never moves a ticket to Done.

## Alternatives and tradeoffs

Tracking CPU/process time would require an agent execution supervisor outside this release. A lifetime timer would conflate separate implementation attempts. Existing tickets without a session timestamp show Start unknown until their next entry into In Progress; no start time is invented.

## Attribution

Implemented by Codex fixes within approved #28 scope; no new execution-supervision capability is implied.

## Stage decoration refinement — 2026-09-30

Codex chat orchestrator, responding to the human review on approved #28: ordinary In Progress tickets now show a larger decorative waveform even before an explicit progress report. Its label says In progress · stage animation, while recent attributed reports retain their separate label. Stage decoration is not evidence of measured activity, elapsed CPU time, or a verified running agent. Stale reports flatten the display and request an update; blocked tickets and expired claims do not animate. Reduced-motion mode retains the visual indicator with all motion stopped.

This changes the earlier UI trigger so the board visibly communicates stage without relying on agents to report before any decoration appears. It does not change reported estimates, ownership, completion, or the current-session elapsed-time rule.
