## Choice

Use pinned, locally served Pixelify Sans for retro body/control typography and Silkscreen for chunky hardware/console display lettering, including Elektron and Game Boy. Ship the original OFL attribution/licenses with the web assets. Use shared theme tokens and one optional window-menu component; the retro desktop presets show actual Save/Close/View commands wired to existing handlers.

Windows 95 uses a blue caption and beveled close button, Windows 3.1 a centered caption and left system-menu-style close gadget, System 7 horizontal title stripes and a left close box, and AmigaOS a blue Workbench-style frame. All keep keyboard-accessible, labeled close controls. Other themes retain their existing window layout.

## Context and rationale

Human review of #19 requested less modern fonts, chunkier Elektron/Game Boy type and OS-inspired window/menu bars. Installed-font fallbacks vary by device and rendered as modern system fonts on macOS. Bundled fonts give repeatable offline rendering and menu commands stay functional instead of decorative.

## Alternatives and tradeoffs

These are original, period-inspired treatments, not exact replicas or extracted proprietary OS font assets. Modern OS font fallbacks were smaller but inconsistent; remote font CDNs would add a network dependency. Pixel display type is limited to suitable headings/controls with more readable proportional pixel text for prose and unchanged monospace code rendering. Existing interactions, record storage and screenshot geometry are reused.
