## Finding

contextMarkdown includes the parent and approved scope titles, but omits their bodies. Agents using next_ticket or get_context cannot see acceptance criteria, constraints, or exclusions kept on the approved parent, even when requesting a full Markdown brief.

## Reproduction and evidence

Created an approved parent whose description restricted work to a parser and prohibited renderer changes, then requested the child Markdown context. The parent title appeared but the scope description was absent.

## Acceptance criteria

- [ ] Include the approved scope description and acceptance criteria in Markdown context, with its identifier and attribution/reference.
- [ ] Include relevant parent context when the direct parent differs from the approved ancestor, without duplicating the same record.
- [ ] Brief mode must preserve approval boundaries and exclusions rather than silently dropping them.
- [ ] Test direct and ancestor approval through the Markdown API/MCP context paths.
