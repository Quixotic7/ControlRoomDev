## Backlog refinement

Prepared by Codex backlog refinement. This describes planned work; implementation has not started.

### Intended outcome

Provide a dedicated vertical planning view where dragging tickets changes the order in which work should be considered.

### Scope and approach

Build on the saved table view and existing manual/priority sorting. Offer an obvious Priority planning preset, rank tickets within priority groups, and allow explicit movement into another priority group. Ordering must not silently change workflow status or parent. Explain that priority is the urgency bucket and rank is the order within it.

### Acceptance criteria

- [ ] The planning view shows a vertical list with priority groups and visible drag handles, including the start/end of each group.
- [ ] Dragging within a group changes persistent relative rank; dragging to another priority group updates priority and rank visibly.
- [ ] Reordering across tickets with different statuses does not move either ticket to the other status or change its parent.
- [ ] Move up/down and move-to-priority controls provide keyboard alternatives, including first/last positions.
- [ ] Reloading or returning to the saved view retains the order; concurrent reorder failures reconcile without losing tickets.
- [ ] Filtered reordering uses defined visible anchors and preserves the relative order of hidden tickets; saved sort modes clearly indicate whether manual reordering is active.

### Implementation notes and related work

Start with web/ProjectPage.tsx place/peersOf, web/TableView.tsx and web/model.ts sortTickets. Current place also copies the target status, so reuse needs care. Coordinate drag preview with #22; prefer existing order metadata over a second competing ranking field.

### Human review / verification

Rank tickets across several stages and priorities, move to first/last, refresh, and repeat with a filter and keyboard controls. Confirm that status/parent stay unchanged and priority changes only when crossing an explicit priority group.
